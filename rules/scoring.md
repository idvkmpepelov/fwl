# Scoring

Match points:

| Action | Points |
|---|---|
| Double-leg takedown | 2, then top |
| Sprawl counter / go-behind style counter | 2 and top |
| Body lock | 0, but secures top |
| Gut wrench, leg lace | 2 |
| Crotch lift, foot-trap leg lift | 2, or 4 if full exposure |
| Half nelson, cradle | 2, or 4 on full exposure, then a pin chance |
| Reversal | 1 and a switch, only from a real bottom exchange |
| Stand-up escape | 0, back to neutral |
| Completed pin | match over |

A failed double leg lets the defender sprawl or crotch-lift. Failed gut, leg lace, or foot-trap can open a reversal. Near-pin is folded into the first 4-point exposure and is not scored again for holding it.

League points, for a team table, not the match score: pin 5, technical superiority 4, ordinary win 3, loss with at least one point scored 1, shutout or being pinned 0.

An action that is still going when the period ends does not score.
